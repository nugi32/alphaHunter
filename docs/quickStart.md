## Quick start

### Prepare an enriched CSV

```bash
python main.py prepare --tf H1
python main.py prepare --tf D1 --limit 5000
```

### Run analysis on an existing enriched CSV

```bash
python main.py run --tf H1
python main.py run --tf H1 --lookaheads 3 5 10
python main.py run --tf H1 --lookaheads 3 5 10 --out results/sweep
```

### Prepare and run in one step

```bash
python main.py all --tf H1
python main.py all --tf H1 --lookaheads 3 5 10
python main.py all --tf D1 --limit 5000 --lookaheads 5
```

## Configuration

- `payload.json` contains the condition library, search depth, minimum sample thresholds, validation split, and lookahead defaults.
- The pipeline expects raw candle data under `data/` and uses timeframe-specific CSV files.

## Outputs

- `payload_{timeframe}.csv` — enriched dataset generated by `prepare`.
- `results/` — ranked candidates, summaries, and generated report outputs.
- `results/la{lookahead}/` — per-lookahead analysis output directories.
