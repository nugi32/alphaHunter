PATTERN DISCOVERY PROCESS
──────────────────────────────────────────────────────────────────────────

Input: 5,819 candles with 40+ indicators each

Step 1: ANALYZE
  For each candle, identify bullish indicators:
  - Continuous: value > median = bullish
  - Binary: value = 1 = bullish (DOJI, COMPRESSION, etc)

Step 2: GROUP
  Group candles with same bullish combination
  Example: [ADX>med, RSI>med, MACD>signal] = Pattern X

Step 3: SCORE
  For each pattern:
  - Count: frequency of pattern
  - Win: % of bullish price moves
  - Payoff: avg win / avg loss
  - Quality: frequency × win_rate × payoff

Step 4: FILTER
  Remove if:
  - Win rate < 51% (not profitable)
  - Payoff < 0.5 (losses > wins)
  - Frequency < 5 (too rare)

Step 5: REPORT
  Rank valid patterns
  Display top 15 in HTML table

Output: 5,288 → 3 valid patterns + 5,285 noise

KEY METRICS EXPLAINED
──────────────────────────────────────────────────────────────────────────

Frequency
  How many times pattern occurred in historical data
  22 occurrences = statistically significant
  
Win Rate
  % of times price went UP when pattern occurred
  95.45% = almost always up
  > 50% = profitable
  
Payoff Ratio
  Average win size ÷ average loss size
  8.89x = wins are 8.89x larger than losses
  > 1.0 = profitable
  
Quality Score
  Frequency × (Win Rate × 100) × Payoff Ratio
  Higher = better pattern
  18658.78 > 2478.59 > 682.26
