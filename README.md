# AlphaHunter

AlphaHunter is a candlestick and indicator brute-force analysis pipeline for discovering recurrent market reactions. It loads raw market data, enriches each candle with technical indicators and pattern flags, builds candidate condition combinations, measures forward price reactions, and filters results by consistency and overfitting risk.

## What the pipeline does

1. Load raw OHLCV data for a selected timeframe.
2. Generate an enriched dataset with indicators, candle patterns, and volume features.
3. Build search-space combinations from the configured payload.
4. Scan all combinations across the dataset.
5. Measure forward price reactions over configured lookahead windows.
6. Apply consistency, frequency, and validation filters.
7. Rank surviving conditions and write reports.

## Quick start

### Prepare an enriched CSV

```bash
python main.py prepare --tf H1
python main.py prepare --tf D1 --limit 5000
```

### Run analysis on an existing enriched CSV

```bash
python main.py run --tf H1
python main.py run --tf H1 --lookaheads 3 5 10
python main.py run --tf H1 --lookaheads 3 5 10 --out results/sweep
```

### Prepare and run in one step

```bash
python main.py all --tf H1
python main.py all --tf H1 --lookaheads 3 5 10
python main.py all --tf D1 --limit 5000 --lookaheads 5
```

## Configuration

- `payload.json` contains the condition library, search depth, minimum sample thresholds, validation split, and lookahead defaults.
- The pipeline expects raw candle data under `data/` and uses timeframe-specific CSV files.

## Outputs

- `payload_{timeframe}.csv` — enriched dataset generated by `prepare`.
- `results/` — ranked candidates, summaries, and generated report outputs.
- `results/la{lookahead}/` — per-lookahead analysis output directories.
